# 人工智能程序设计与实践 · lesson01

第 1 次课作业《AI 辅助编程初体验》：以"复利计算"为例，完成最小版、交互版、单利对比版三个程序，并扩展参数校验、表格对齐和月复利研究。

## 目录结构

```
lesson01/
├── compound_min.py       # 最小版：固定本金/利率/年限，按年复利
├── compound_input.py     # 交互版：键盘输入，校验负利率、本金、年限
├── compound_compare.py   # 对比版：单利 vs 复利逐年对齐表格
├── compound_monthly.py   # 研究任务：按月复利（n=12）与年复利对比
├── .gitignore            # 研究任务：忽略规则及理由
├── AI使用记录.md          # AI 关键指令原文与本人验证过程
└── 进度报告一.md          # 课堂实践进度报告
```

## 运行方法

需要 Python 3，在 `lesson01/` 目录下执行：

```bash
python compound_min.py        # 最小版
python compound_input.py      # 交互版（按提示输入）
python compound_compare.py    # 单利/复利对比表
python compound_monthly.py    # 月复利研究
```

公式：

- 单利：`本息 = 本金 × (1 + 年利率 × 年限)`
- 复利（每年计息 n 次）：`本息 = 本金 × (1 + 年利率 / n) ** (n × 年限)`
